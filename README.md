# Prácticas de desarrollo web — 2024

Colección de ejercicios académicos de HTML, CSS y JavaScript. Conserva prácticas separadas para mostrar el aprendizaje progresivo de estructura, estilos e interacción en el navegador.

## Organización
| Carpeta | Contenido |
|---|---|
| `PAR1/` | Página sobre Gerardo Barrios con estilos y eventos JavaScript. |
| `Pagina-Web-Semana-4-main/` | Práctica de página web con recursos multimedia. |
| `Progra4/` | Ejercicio sobre expectativas del año, con estilos y scripts. |
| `primer lab/` | Páginas iniciales y ejercicio de distribución con grid. |

## Tecnologías
HTML, CSS y JavaScript, sin backend ni proceso de compilación.

## Ejecutar
Desde la raíz:
```bash
python -m http.server 8000
```
Abre `http://localhost:8000` y entra al archivo HTML del ejercicio que quieras consultar.

## Alcance
Este repositorio reúne prácticas independientes; no representa una única aplicación terminada. Su valor es documentar fundamentos de maquetación, recursos multimedia y eventos del DOM.
